服务器规则

✦ Nalxer · 和谐共建 ✦
▸ 一句话版本
互相尊重、别作弊、别偷别拆。
下面是完整规则与处罚说明，进服即视为已阅读并同意。
1互相尊重
不辱骂、不挑衅、不人身攻击。对事不对人，有矛盾找管理而不是对喷。
2禁止作弊
禁止使用外挂、透视、连点器、自动脚本等违规作弊方式。任何形式的自动化辅助都不允许。
3禁止偷窃
未经允许不得拿取他人物品，包括箱子、展示框、机械产出等。
4禁止破坏
不得恶意破坏他人建筑、红石设备、地形。挖矿与探索请避开已圈定的领地。
5禁止卡服行为
禁止高频红石与刷物品。这类行为会直接拖垮服务器，一经发现立即处理。
6禁止恶意加载区块与数据包攻击
不得通过异常手段强制加载区块或发送恶意数据包。此类行为会被永久封禁且不接受申诉。
▸ 违规怎么处理
服务器装有管理插件，会记录违规行为、并支持 临时封禁 / 封禁 / 禁言 / 限制交互。 处罚按情节轻重与次数递增，严重违规（作弊、卡服、恶意攻击）可直接永久封禁。
违规类型 常见处理方式
言语冲突 / 刷屏 禁言 数小时至数天
偷窃 / 破坏 临时封禁 并追回损失，情节严重直接 封禁
作弊 / 外挂 封禁（账号），必要时 封禁 IP
卡服 / 恶意攻击 永久封禁，不接受申诉
▸ 被封了怎么办
如果你认为处罚有误，请带着 游戏 ID、时间 和 当时在做什么 到 QQ 群 839126641 说明情况， 管理会核对记录后回复。
恶意申诉、伪造证据会加重处罚。
▸ 遇到违规怎么举报
在游戏内使用 /linux report <玩家> <原因> 提交举报， 会记录到管理员后台，管理会在调查后处理并回复你。
也可以直接到 QQ 群 839126641 找管理。
