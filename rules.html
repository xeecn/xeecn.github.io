▸ 一句话版本
互相尊重、别作弊、别偷别拆。
下面是完整规则与处罚说明，进服即视为已阅读并同意。
轻度 违反封禁 1-7 天
1禁止盗窃其他玩家物品
包括箱子、展示框、机械产出等，未经允许不得拿取。
2禁止一直击杀其他玩家
PVP、竞技场等约定玩法除外；不允许针对同一玩家反复击杀。
3禁止损坏服务器主城周围地形
主城周边为公共区域，挖坑、放水放岩浆、堆放杂物都不允许。
中度 违反封禁 7-30 天
4禁止毁坏玩家建筑
包括拆墙、放火、灌水、破坏红石线路等一切破坏行为。
5禁止毁坏公共建筑
出生点、主城、公共设施与地标均属公共建筑。
6禁止使用 TNT 等毁坏服务器地形
TNT、床炸、凋灵、苦力怕诱导等，一律按破坏地形处理。
7禁止在其他玩家建筑物中使用幸运方块
幸运方块可能产生爆炸或大范围改变地形，请在自家空旷处使用。
8禁止盗取服务器地图画
地图画为服务器公共装饰，取下即视为盗取。
9禁止持有违规道具
例如 32k 等超出正常范围的武器、工具与道具。
10禁止大量刷珍贵物品刷货币
利用机制漏洞或重复操作大量产出物品、货币，均属违规。
11请尊重其他玩家领地
禁止以任何方式毁坏或绕过其他玩家的领地保护。
重度 违反封禁 30 天-永久（ID+IP 封禁）
12非 OP 持有命令方块，且拒不归还
发现后请立即上交管理；拒不归还按重度处理。
13使用一系列手段攻击服务器
包括但不限于压测、发包、漏洞利用等。
14制造大型卡服机、禁人塔等
高频红石、批量实体、恶意区块加载等均属此类。
15盗取服务器 OP 权限
任何形式的提权尝试都按最高档处理。
16绕过服务器登录 / 领地插件限制
包括绕过登录验证、绕过领地保护、绕过插件限制等。
17盗取他人账号
账号安全由玩家自负，但盗号行为一经查实永久封禁。
18使用外挂
透视、飞行、加速、自动脚本等一律按外挂处理。
19其他违规行为，且态度恶劣，拒不改正
以管理组判定为准；态度与改正情况会影响最终处罚。
★ 第 12-18 条一旦触犯，直接永久封禁（ID+IP 封禁）。
# 此规则对 fs1 可能无效！！！
祝愿正常玩家玩得开心！！！
▸ 违规怎么处理
服务器装有管理插件，会记录违规行为、并支持 临时封禁 / 封禁 / 禁言 / 限制交互。 处罚按情节轻重与次数递增，严重违规（作弊、卡服、恶意攻击）可直接永久封禁。
违规类型 常见处理方式
言语冲突 / 刷屏 禁言 数小时至数天
偷窃 / 破坏 临时封禁 并追回损失，情节严重直接 封禁
作弊 / 外挂 封禁（账号），必要时 封禁 IP
卡服 / 恶意攻击 永久封禁，不接受申诉
▸ 被封了怎么办
如果你认为处罚有误，请带着 游戏 ID、时间 和 当时在做什么 到 QQ 群 839126641 说明情况， 管理会核对记录后回复。
恶意申诉、伪造证据会加重处罚。
▸ 遇到违规怎么举报
在游戏内使用 /linux report <玩家> <原因> 提交举报， 会记录到管理员后台，管理会在调查后处理并回复你。
也可以直接到 QQ 群 839126641 找管理。
